# Deviations

Every departure from the frozen plan (`protocol/analysis/plan.md`), dated. Each row says what changed,
why, and what it does to validity, and names the commit that declared it. That commit's timestamp is
the evidence of when the deviation was declared; its full original wording is kept in the history of
this file (`git show <commit>:protocol/deviations.md`). The rows after the freeze were declared before
the data they concern.

This file is outside the hashes of the freeze on purpose, so that rows added after the freeze leave
the frozen files unchanged. It was drafted with an AI assistant from the student's decisions.
